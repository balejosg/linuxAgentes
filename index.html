¿Por qué usar esta VM con Agentes de IA?

Diseñada para dar autonomía a los agentes sin comprometer tu sistema principal.

🛡️

Aislamiento Real (Sandbox)

Los agentes pueden instalar paquetes, levantar contenedores Docker, abrir puertos o ejecutar scripts destructivos dentro de la VM sin tocar tu máquina real.

📁

Flujo Híbrido Host ↔ VM

Edita tu código cómodamente en tu editor del anfitrión dentro de la carpeta compartida ~/trabajo y deja que los agentes compilen, prueben y desplieguen dentro de Arch Linux.

📐

Contexto Unificado (AGENTS.md)

Todos los agentes preconfigurados comparten directrices claras de ingeniería, contenedores limpios, Bash seguro y diagnóstico directo de sistemas.

Agentes de IA Preinstalados y Configurados

Listos para ejecutarse desde la terminal nada más arrancar la máquina.

OpenCode v2 v2.4.2

Agente de código abierto para terminal instalado desde el canal oficial v2 (opencode.ai/v2/install) en /usr/local/bin/opencode. 

cd ~/trabajo/proyectos
opencode
Herdr CLI v0.9.5

CLI para gestión y ejecución de flujos con agentes, disponible globalmente en /usr/local/bin/herdr. 

herdr --version
Antigravity CLI agy

Reglas del asistente ya instaladas en ~/.gemini/antigravity-cli/rules/ y ~/.gemini/rules/. 

paru -S antigravity-cli
agy

⚡ Puesta en marcha en 3 pasos

  1. Descarga ArchLinux-Agentes.ova e impórtalo en VirtualBox (Archivo → Importar servicio virtualizado).
  2. Opcionalmente, vincula una carpeta local con el nombre trabajo (Automontar y Hacer permanente).
  3. Inicia la VM, conéctate por SSH y lanza tu agente:
ssh -p 2222 usuario@127.0.0.1
cd ~/trabajo/proyectos
opencode

🔧 Reproducir o personalizar desde cero

Todo el entorno se genera de forma automatizada mediante los dos scripts incluidos en el repositorio:

  • • scripts/crear-vm.sh: Descarga la imagen oficial Arch-Linux-x86_64-basic.qcow2, la convierte a VDI y registra la VM en VirtualBox.
  • • scripts/provision.sh: Actualiza el sistema (pacman -Syu), configura idioma, usuario, Docker, OpenCode v2, Herdr, reglas AGENTS.md y /etc/fstab.
./scripts/crear-vm.sh
# Dentro de la VM:
sudo bash /tmp/provision.sh
